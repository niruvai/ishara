# ইশারা (Ishara) ✋

**ওয়েবক্যাম দিয়ে হাতের ইশারায় ম্যাক চালান।** কোনো বাড়তি হার্ডওয়্যার লাগে না। ম্যাকের বিল্ট-ইন ক্যামেরা আপনার হাতের ২১টা গাঁট ট্র্যাক করে, আর কার্সর, ক্লিক, স্ক্রল টাচের মতো কাজ করে। সব প্রসেসিং আপনার ম্যাকেই হয়, কোনো ভিডিও বাইরে যায় না।

*Control your Mac with hand gestures from your webcam — on-device, free & open source (MIT).*

## ইশারাগুলো

| ইশারা | কাজ |
|---|---|
| 🖐 খোলা হাত (চার আঙুল উপরে) | কার্সর চালু হয়, তালুর সাথে চলে |
| ✊ মুঠি / ফ্রেম থেকে হাত সরানো | কার্সর থেমে যায় (park) |
| 👆 তর্জনী নামানো | ক্লিক; নামিয়ে রেখে নাড়ালে ড্র্যাগ |
| 👆👆 একই জায়গায় দ্রুত আবার | ডাবল / ট্রিপল ক্লিক |
| কনিষ্ঠা নামানো | রাইট ক্লিক (ধরে রাখলে রাইট-ড্র্যাগ) |
| ✌️ বা 🤘 পোজ, তারপর হাত একটু উপরে / নিচে ধরে রাখা | জয়স্টিক স্ক্রল — যত দূরে, তত দ্রুত; মাঝখানে ফিরলে থামে |
| 👍 মুঠি + বুড়ো আঙুল উপর / নিচ / বাম / ডান | Mission Control / App Exposé / আগের / পরের ডেস্কটপ |
| 🤙 শাকা | কাস্টম (Spotify/Music-এ প্লে/পজ) |
| 🙌 দুই হাত খুলে দুবার ক্রস | ট্র্যাকিং বন্ধ / চালু |
| কার্সর স্থির রাখা (Dwell click চালু থাকলে) | নিজে থেকে ক্লিক |

## কেন মসৃণ

- **One Euro filter** — স্থির থাকলে কাঁপে না, দ্রুত নাড়ালে ল্যাগ হয় না
- **১২০ Hz কার্সর ড্রাইভার** — ক্যামেরা ৩০ FPS হলেও কার্সর সেকেন্ডে ১২০ বার মসৃণভাবে আপডেট হয়
- **পিক্সেল-স্মুথ স্ক্রল** — ট্র্যাকপ্যাডের মতো
- **3D কোণ দিয়ে ক্লিক মাপা** — তর্জনী মধ্যমার তুলনায় কত ডিগ্রি নামলো, তাই হাত কাত হলে ভুল ক্লিক হয় না
- **দূরত্ব অনুযায়ী এলাকা (Auto reach)** — কাছে বা দূরে বসলেও পুরো স্ক্রিনে পৌঁছানো যায়

## ইনস্টল

macOS, Python 3.10+ লাগবে।

```bash
git clone https://github.com/niruvai/ishara.git
cd ishara
python3 -m venv venv && source venv/bin/activate
pip install -r requirements.txt
python ishara.py --preview     # প্রথমবার প্রিভিউ সহ চালিয়ে দেখুন
python ishara.py               # মেনু বারে চলবে
```

অথবা `Ishara.command` ফাইলে ডাবল-ক্লিক করুন (প্রথমবার নিজেই সেটআপ করে নেবে)।

### অনুমতি (একবারই)
System Settings → Privacy & Security:
- **Camera** → Terminal চালু
- **Accessibility** → Terminal চালু (না দিলে কার্সর নড়বে না)

অনুমতি দেওয়ার পর Terminal ⌘Q করে আবার খুলুন।

## সেটিংস

প্রথমবার চালালে `config.json` তৈরি হয়। মেনু বার → "Settings ফাইল খুলুন"।

| সেটিং | মানে |
|---|---|
| `click_sensitivity` | 0–1, বেশি = সহজে ক্লিক |
| `smoothing` | 0 = দ্রুত, 1 = খুব মসৃণ |
| `cursor_anchor` | `palm` বা `fingertip` |
| `reach_mode` | `auto` বা `manual` |
| `scroll_mode` | `joystick` (ধরে রাখলে একটানা) বা `drag` (টাচের মতো টানা) |
| `scroll_speed`, `scroll_invert`, `horizontal_scroll` | স্ক্রলের গতি, দিক, আড়াআড়ি |
| `dwell_click`, `dwell_ms` | স্থির রাখলে ক্লিক |
| `gestures` | প্রতিটা ইশারার অ্যাকশন: `shortcut` (যেমন `cmd+shift+4`), `app` (অ্যাপের নাম), `command` (শেল কমান্ড), `none` |
| `per_app` | নির্দিষ্ট অ্যাপে ইশারার আলাদা অ্যাকশন |
